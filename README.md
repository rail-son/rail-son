| **APIs & Integrações** | Integrações REST e SOAP entre sistemas corporativos, APIs para consumo externo, autenticação segura e controle de rotas |

- 🛡️ **Ownership** — conduzo demandas de ponta a ponta, do entendimento à entrega e ao acompanhamento em produção.
